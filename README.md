A **minimal AI-powered dictionary web app** that explains any word in **2–4 simple lines**.

Built with **HTML, Tailwind CSS, and JavaScript**, and powered by the **Groq API using the Llama-3.1-8B-Instant model**.

The goal of this project is to demonstrate a **simple AI product interface with minimal UI and fast AI inference**.

---

# Demo

Type any word and get a **short explanation generated by AI**.

Example:

```
Gravity
Gravity is the force that pulls objects toward each other,
especially toward Earth.
```

# Getting a Groq API Key

This project requires a **Groq API key**.

Steps:

### 1. Create a Groq account

Visit:

https://console.groq.com

Sign up or log in.

---

### 2. Create an API key

Go to:

```
API Keys
```

Click:

```
Create API Key
```

Copy your key.

Example format:

```
gsk_xxxxxxxxxxxxxxxxxxxxxxxxx
```

---

### 3. Add the API key to the project

Open:

```
script.js
```

Find this line:

```javascript
const GROQ_API_KEY = "YOUR_GROQ_API_KEY";
```

Replace it with your key:

```javascript
const GROQ_API_KEY = "gsk_your_real_key_here";
```

# Security Note

This project calls the **Groq API directly from the frontend**.

Because of this:

- The API key will be visible in the browser.
- This is acceptable for **learning and prototypes**.

For production applications the recommended architecture is:

```
Frontend → Backend → Groq API
```

This prevents exposing API keys.
